# NEXUS · Buda GIS Command Center

City limits + ETJ intelligence plate for Buda, Hays County, Texas.

Self-contained HTML/JS. Canvas boundary visualizer, Leaflet overlay, property query, PNG and PDF export. Official source of truth remains the City of Buda ArcGIS Hub.

- Live: https://antmanthepro.github.io/nexus-buda-gis/
- Official GIS: https://map-budatx.hub.arcgis.com/
- City Limits layer: https://map-budatx.hub.arcgis.com/datasets/buda-city-limits

DoubleA @ AntManThePro

Artistic polygons are for demonstration. Property and permitting decisions use the official map.
